# Oasis Timer 🌿

An elegant, all-in-one focus and productivity suite designed to help you master your workflow, maintain mindfulness, and eliminate distractions. Built entirely as a lightweight, single-file web application.

![Oasis Timer Banner](https://img.shields.io/badge/Status-Active-teal?style=for-the-badge)
![HTML5](https://img.shields.io/badge/HTML5-TailwindCSS-orange?style=for-the-badge)

---

## ✨ Features

* **⏳ Customizable Focus Sessions:** Tailor your deep work blocks to match your ideal rhythm.
* **🗺️ Journey Map & Milestones:** Scheduled alerts and check-ins keep you on track throughout your session.
* **✅ Session Task List:** Keep track of your micro-goals right alongside your active timer.
* **🎵 Built-in Audio Chimes:** Gentle synthesized tones, singing bowls, and deep gongs signal your milestones.
* **🌧️ Ambient Noise Generator:** Powered by the Web Audio API to generate **White Noise**, **Soft Rain**, and **Cosmic Drone** sounds directly in your browser—no downloads required.
* **📊 Productivity Insights:** Track your deep work time, completed blocks, and break adherence locally over time.
* **🌙 Dark & Light Mode:** Seamlessly switch themes to match your environment.
* **⌨️ Keyboard Shortcuts:** Quick control using the **Spacebar** (start/pause) and **Escape** (dismiss modals).

---

## 🚀 Quick Start / Local Development

Because Oasis Timer is contained entirely within a single file, running it locally is effortless:

1. Clone or download this repository.
2. Ensure your main file is named **`index.html`**.
3. Double-click the file or open it in any modern web browser (Chrome, Edge, Safari, Firefox).
